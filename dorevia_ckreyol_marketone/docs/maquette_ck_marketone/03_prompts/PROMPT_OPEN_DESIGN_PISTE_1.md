# Prompt Open Design - CK Marketone - Piste 1

Create a high-fidelity responsive HTML prototype for an e-commerce marketplace called "C-Kreyol Marketone".

Context:
C-Kreyol Marketone is a commerce channel for products from Creole-speaking territories. It is not a generic exotic shop and not only an Antillean product site. The product doctrine is:

"Le produit d'abord. Le recit ensuite. Le savoir en prolongement."

The site has three worlds:
- Boutique: buy products
- Culture: discover territories, producers, languages and uses
- Savoirs: transmit recipes, vocabulary, traditions and techniques

Build the first design direction: "Marche creole contemporain".

Visual direction:
- modern, warm, trustworthy marketplace
- product-first e-commerce interface
- subtle cultural storytelling, never overwhelming the shop
- premium but accessible
- strong scanability and conversion
- suitable for implementation in Odoo Website / Website Sale
- avoid a generic tropical/exotic look
- avoid a one-color palette
- avoid excessive rounded cards, oversized marketing sections, decorative blobs, or abstract gradients

Pages / sections to include in one prototype:

1. Sticky header
- brand: C-Kreyol
- navigation: Boutique, Culture, Savoirs
- search input
- icons/actions for account, wishlist, cart

2. Homepage first viewport
- strong marketplace identity
- primary CTA to shop
- secondary CTA to discover origins
- visible product/category signal above the fold
- concise promise in French

3. Boutique grid
- sidebar filters for categories, collections and origins
- grid of product cards
- product cards must show image area, origin label, category, price, wishlist, quick add
- include sort and active filter state

4. Product detail preview
- product image gallery area
- title, origin, short story, price, quantity, add to cart
- small "origine et usage" block below purchase area

5. Culture / origins strip
- lightweight editorial section linking territories and stories
- do not dominate the commerce experience

6. Cart / checkout preview
- compact order summary
- reassuring delivery/payment block

Use realistic French UI copy.
Use placeholder product names inspired by Creole-speaking territories, for example:
- Confiture goyavier Reunion
- Cafe Bourbon Pointu
- Epices colombo
- Sirop tamarin
- Savon artisanal vetiver
- Piment confit maison

Design requirements:
- responsive desktop and mobile
- polished spacing and typography
- no overlapping text
- stable card dimensions
- use icon buttons for account, wishlist, cart and quick actions
- keep cards at 8px radius or less
- product-first visual hierarchy
- include enough CSS in the artifact to make the prototype look complete

Deliverable:
Single self-contained HTML artifact with CSS and minimal JavaScript only if useful for tabs/filter visual state. Do not include framework setup.
