# Brief synthétique — Direction artistique Phase 1

**Projet : C-Kreyol**

**Documents liés** : [CHARTE_GRAPHIQUE_PHASE1.md](CHARTE_GRAPHIQUE_PHASE1.md) (arbitrages minimaux à figer), [DIRECTIONS_ARTISTIQUES_PHASE1.md](DIRECTIONS_ARTISTIQUES_PHASE1.md) (réponse au brief, **3 pistes** + recommandation), [DESIGN.md](DESIGN.md), [SPEC_HERO_HOMEPAGE.md](SPEC_HERO_HOMEPAGE.md), [WIREFRAME_HOMEPAGE.md](WIREFRAME_HOMEPAGE.md), [ARCHITECTURE_DECISION_RECORD.md](ARCHITECTURE_DECISION_RECORD.md) (**ADR-CKR-002** / **ADR-CKR-003**), [NOTE_DE_CADRAGE.md](NOTE_DE_CADRAGE.md), [README](../../README.md).

---

## 1. Objet

Définir une **direction artistique Phase 1** pour **C-Kreyol**, afin de poser une base **visuelle** claire, **cohérente** et **exploitable** pour le **front-end** du site.

L’objectif **n’est pas** de produire une **charte d’agence exhaustive**, mais de proposer une **direction artistique forte et juste**, suffisante pour guider :

- le **hero** de la homepage ;
- le **menu principal** ;
- le **footer** ;
- le **thème global** du site.

---

## 2. Ce qu’est C-Kreyol

**C-Kreyol** est un **canal e-commerce spécialisé** centré sur des **produits agro transformés antillais**.

Le projet doit être compris comme :

- une **marque propre** ;
- un **canal retail digital** ;
- un site de vente en ligne **sérieux**, **lisible** et **désirable**.

Ce **n’est pas** :

- un simple site vitrine ;
- un site **standard Odoo** laissé tel quel ;
- le site de **La Platine**.

**La Platine** est le **premier fournisseur** du projet, mais **C-Kreyol** doit conserver une **identité de marque distincte**.

---

## 3. Rappel important sur La Platine

**La Platine** est un **fabricant artisan** de :

- **biscuits** ;
- d’autres **produits secs et sucrés à base de farine de manioc** ;
- ainsi que de produits tels que des **crêpes de manioc fourrées de confitures** à base de **fruits tropicaux**.

Ce point compte pour la direction artistique : l’univers visuel ne doit pas basculer vers un **générique « Antilles »** flou ; il doit pouvoir accueillir une réalité **produit** plus **précise**, **artisanale**, **gourmande** et **crédible**.

---

## 4. Positionnement recherché

Une direction qui fasse sentir que C-Kreyol est :

- **sérieux** ;
- **chaleureux** ;
- **accessible** ;
- **retail** ;
- **non folklorique** ;
- **non cheap** ;
- **distinct d’un front standard Odoo**.

Le site doit donner **envie d’explorer et d’acheter**, tout en restant **crédible** et **sobre**.

---

## 5. Inspirations de référence

### A. La Maison des Antilles

Référence utile pour :

- la **crédibilité marché** ;
- la perception d’un **acteur installé** ;
- la lisibilité d’un **univers de produits antillais**.

### B. Caribshopper

Référence utile pour :

- la **logique retail digital** ;
- la **navigation** ;
- les **collections** ;
- la **mise en scène de l’offre** ;
- la **perception de marque**.

Il ne s’agit **pas** de copier l’un ou l’autre, mais d’en tirer une **synthèse adaptée à C-Kreyol** (cf. [DESIGN.md §3](DESIGN.md)).

---

## 6. Intention créative

Le site doit évoquer :

- des **produits réels** ;
- une **origine lisible** ;
- une sensation de **sélection** ;
- une qualité de **retail spécialisé** ;
- une marque qui a du **goût**, sans **surcharge décorative**.

À éviter :

- les **clichés exotiques** ;
- le **folklore visuel** ;
- le rendu **« marché touristique »** ;
- la **surcharge** de couleurs agressives ;
- le côté **« template e-commerce générique »**.

---

## 7. Points structurants déjà décidés

- Le **front-end** est le principal espace de **spécifique légitime** du projet en Phase 1 ([ADR-CKR-002](ARCHITECTURE_DECISION_RECORD.md#adr-ckr-002)).
- Le **menu principal** et le **footer** doivent être **entièrement personnalisés** ([ADR-CKR-003](ARCHITECTURE_DECISION_RECORD.md#adr-ckr-003)).
- Le site doit être **très bon sur mobile** (must have, cf. note [§6.1](NOTE_DE_CADRAGE.md) / [DESIGN.md](DESIGN.md)).
- Le **hero** de la homepage doit faire comprendre **immédiatement** :

  - qu’on vend des **produits agro transformés antillais** ;
  - via un **canal retail digital spécialisé** porté par la marque **C-Kreyol** ;

  (détail : [SPEC_HERO_HOMEPAGE.md](SPEC_HERO_HOMEPAGE.md), [WIREFRAME_HOMEPAGE.md](WIREFRAME_HOMEPAGE.md) bloc 2.)

- **Dans le hero** (tranché, cf. [SPEC_HERO_HOMEPAGE.md §4](SPEC_HERO_HOMEPAGE.md)) :

  - **Nantes** n’est **pas** mis en avant ;
  - **La Platine** ne doit **pas** absorber la marque dans le **message principal** du hero ;
  - l’**origine des produits** peut en revanche être **visible**, si formulation **sobre** et **alignée** sur l’offre réelle ([ADR-CKR-005](ARCHITECTURE_DECISION_RECORD.md#adr-ckr-005)).

---

## 8. Livrable attendu (création / direction)

**Proposer 1 à 3 directions artistiques** possibles pour C-Kreyol. Pour **chacune** :

- un **ton visuel** (mots-clés) ;
- une **palette** indicative ;
- une ou deux **typographies** ;
- une **direction photo / image** ;
- une **intention de hero** (cohérente avec la spec) ;
- une idée du style de **navigation** et de **footer** ;
- éventuellement des **mots-clés** de perception de marque.

Objectif : une **direction Phase 1** suffisamment **nette** pour lancer le travail **front-end** sans repartir de zéro à chaque arbitrage — en convergence avec [CHARTE_GRAPHIQUE_PHASE1.md](CHARTE_GRAPHIQUE_PHASE1.md).

---

## 9. Forme du retour

Un livrable **court** suffit, par exemple :

- **1 à 3 pistes créatives** ;
- quelques **références visuelles** ou **intentions** ;
- une **recommandation** de direction **prioritaire** (ou critères de choix).

---

## 10. Formule courte du projet

**C-Kreyol** doit être perçu comme un **canal retail digital spécialisé** pour des **produits agro transformés antillais**, avec une identité **sérieuse**, **chaleureuse**, **lisible** et **non folklorique**.
