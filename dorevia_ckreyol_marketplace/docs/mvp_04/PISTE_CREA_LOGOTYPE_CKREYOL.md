# PISTE CREA — Logotype C-Kréyòl

**Statut** : piste créa avant intégration définitive  
**Sujet** : logotype header / marque affichée  
**Module concerné** : `dorevia_ckreyol_marketplace`  
**Contexte lié** : Header CK V1 / MVP04

---

## 1. Intention

Le header CK commence à trouver une direction cohérente :

- structure e-commerce claire ;
- Top_0 sobre ;
- recherche intégrée ;
- panier / favoris visibles ;
- navigation Top_2 lisible ;
- distinction plus nette entre boutique, communauté et professionnels.

Le prochain point créa concerne le **logotype affiché dans le header**.

Objectif : tester une version du logo plus incarnée, plus culturelle, mais toujours sobre, lisible et compatible avec un header e-commerce.

Il ne s'agit pas de produire un logo décoratif ou folklorique, mais un **mot-signe** plus fort qu'un simple texte brut.

---

## 2. Doctrine de nommage

```text
C-Kreyol  = version web / pratique / ASCII
C-Kréyòl  = version marque / culturelle / éditoriale
```

| Forme | Usage |
|------|------|
| `C-Kreyol` | URLs, slugs, code, variables, fichiers, noms techniques, usages ASCII |
| `C-Kréyòl` | Logo, marque affichée, éditorial, supports visuels, header public |

Le logo est donc une **stylisation de `C-Kréyòl`**.

---

## 3. Objectif créa

Créer ou ajuster un logotype `C-Kréyòl` qui soit :

- sobre ;
- lisible ;
- chaleureux ;
- éditorial ;
- légèrement culturel ;
- compatible avec le header actuel ;
- exploitable en petit format.

La marque doit gagner en personnalité, sans perdre en clarté.

---

## 4. Direction souhaitée

Tester une typographie avec une légère :

- cursivité ;
- inflexion calligraphique ;
- souplesse manuscrite ;
- tension organique dans certaines lettres.

Important : il ne s'agit **pas** d'une écriture manuscrite complète.

Direction cible :

```text
serif elegante + legere souplesse + tres bonne lisibilite
```

Le logo reste premium et lisible, pas une signature manuscrite.

---

## 5. Pistes à explorer

### Piste A — Très sobre

- serif élégante ;
- très peu de mouvement ;
- logo proche d'un wordmark premium ;
- excellente lisibilité ;
- adaptation facile au header.

### Piste B — Plus vivante

- légère cursivité ;
- formes un peu plus organiques ;
- caractère culturel plus sensible ;
- toujours compatible header.

### Piste C — Intermédiaire

- équilibre sobriété / geste ;
- un peu de souplesse, sans effet script ;
- piste probablement la plus réaliste pour le header.

---

## 6. Points typographiques à surveiller

Attention particulière sur :

- `C` ;
- `K` ;
- `y` ;
- `é` ;
- `ò`.

Les accents doivent être intégrés au dessin, sans effet ajouté artificiellement.

Le `ò` est structurant dans la personnalité du mot `Kréyòl`.

---

## 7. Couleur

Base possible :

```text
#8D3B26
```

La couleur doit rester :

- chaude ;
- lisible ;
- non agressive ;
- cohérente avec les CTA et accents du site ;
- compatible avec fond clair du header.

Éviter les rouges trop vifs / promotionnels.

---

## 8. Contraintes header

Le logotype doit fonctionner dans le header actuel :

- lisible desktop ;
- lisible mobile ;
- net à petite taille ;
- pas trop large ;
- pas trop haut ;
- pas de détails trop fins ;
- intégration propre avec recherche et actions client ;
- rendu SVG propre ;
- pas de déséquilibre visuel du header.

Le logo doit rester efficace dans un contexte e-commerce.

---

## 9. GO créa

GO si :

- `C-Kréyòl` immédiatement lisible ;
- accents propres et naturels ;
- rendu plus vivant qu'un texte brut ;
- personnalité marque renforcée ;
- sobriété conservée ;
- encombrement header maîtrisé ;
- comportement correct desktop + mobile ;
- pas d'effet folklorique ;
- pas d'effet luxe générique.

---

## 10. NO GO créa

NO GO si :

- logo trop manuscrit ;
- lisibilité en baisse ;
- accents mal rendus ;
- rendu trop décoratif ;
- style folklorique ;
- style trop institutionnel ;
- style luxe générique ;
- déséquilibre header ;
- détails perdus en petite taille ;
- simple police posée sans intention.

---

## 11. Base SVG indicative

Cette base est un point de départ, non une contrainte d'exécution :

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 400 100">
  <text
    x="50%"
    y="60%"
    text-anchor="middle"
    font-family="'Noto Serif', serif"
    font-weight="700"
    font-size="48"
    fill="#8D3B26"
    letter-spacing="-1"
  >
    C-Kréyòl
  </text>
  <path
    d="M120 70 Q 130 75 145 70"
    stroke="#8D3B26"
    stroke-width="2"
    fill="none"
    stroke-linecap="round"
  />

```

Le tracé décoratif est optionnel.  
L'intention centrale : **`C-Kréyòl` comme mot-signe sobre, vivant et culturellement ancré**.

---

## 12. Attendu

Proposer une première piste de logotype `C-Kréyòl` pour le header :

- une version très sobre ;
- une version légèrement plus cursive / vivante ;
- une recommandation créa d'intégration.

La proposition est évaluée **en contexte header**, pas isolée.

---

## 13. Validation en contexte

Vérifier la piste sur :

- homepage ;
- boutique `/shop` ;
- page demande compte professionnel ;
- desktop ;
- mobile ;
- fond clair du header ;
- taille réelle d'affichage.

Le logo n'est validé qu'en contexte réel de navigation.

---

## 14. Synthèse courte

```text
Logo affiche : C-Kréyòl
Usage technique : C-Kreyol
Direction : serif elegante + legere cursivite
Objectif : plus vivant, plus culturel, plus editorial
Garde-fou : sobre, lisible et compatible header
```
