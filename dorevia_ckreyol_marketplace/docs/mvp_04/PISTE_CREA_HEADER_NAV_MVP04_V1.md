# Piste créa — Header CK MVP04 / V1

**Statut** : piste créa / UX avant développement  
**Ticket lié** : `HEADER-NAV-MVP04`  
**Dossier lié** : `docs/mvp_04/` — panier & favoris  
**Module** : `dorevia_ckreyol_marketplace`

---

## 1. Intention

Cette piste accompagne la nouvelle posture : construire une **Header CK V1** en trois niveaux, sans attendre un chantier long terme.

Référence structure :

```text
Top_0 — Barre flash info
Top_1 — Actions utiles client
Top_2 — Exploration boutique / contenus
```

Objectif : valider une direction visuelle claire, e-commerce, compatible desktop et mobile, puis livrer par lots V1.1 / V1.2 / V1.3.

---

## 2. Direction V1

### Top_0 — Flash info

- barre fine ;
- texte court ;
- une seule information ;
- neutralisable facilement.

Exemple :

```text
Livraison offerte dès X € d’achat en France métropolitaine.
```

### Top_1 — Actions utiles

- logo ;
- recherche discrète (icône ou champ court) ;
- aide / contact ;
- compte / connexion ;
- favoris ;
- panier + compteur.

### Top_2 — Exploration

```text
Tous les produits | Promotions | Collections | Idées cadeaux | Recettes | Professionnels
```

Entrée `Professionnels` :

```text
/demande-compte-professionnel
```

---

## 3. Priorités visuelles

1. identité / logo ;
2. navigation principale ;
3. panier ;
4. favoris ;
5. professionnels.

Rappel doctrine :

```text
Panier = achat immédiat
Favoris = intention / sélection
Professionnels = demande d’ouverture de compte pro
```

---

## 4. Desktop (V1.1)

Piste simple :

```text
Logo | Navigation principale | Professionnels | Compte | Favoris | Panier
```

Variant possible avec recherche :

```text
Logo | Recherche discrète | Navigation principale | Professionnels | Favoris | Panier
```

---

## 5. Mobile (V1.2)

Pistes :

```text
Logo | Recherche | Favoris | Panier | Menu
```

ou

```text
Logo | Compte | Favoris | Panier | Menu
```

`Professionnels` reste accessible dans le menu mobile.

---

## 6. Ce que V1 ne couvre pas

- méga-menu ;
- recherche avancée / autocomplete ;
- animations lourdes ;
- personnalisation marketing avancée ;
- logique snippet complète ;
- refonte checkout ;
- refonte éditoriale profonde.

---

## 7. Critères GO créa/UX

- panier visible sans chercher ;
- favoris visibles mais secondaires ;
- professionnels accessibles sans ambiguïté ;
- recherche discrète ;
- mobile lisible sans surcharge ;
- rendu global sobre et cohérent CK.
