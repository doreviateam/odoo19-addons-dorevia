**Date** : 2026-04-28  
**Statut** : version opérationnelle v1

---

## 1) Objectif de la charte

Cette charte définit un cadre éditorial simple, durable et maintenable pour enrichir les fiches produit sans refonte technique.

Elle vise à garantir :

- une information utile à l’achat ;
- un ton C-Kreyol cohérent ;
- une promesse crédible ;
- une rédaction sincère, sans surpromesse ;
- une homogénéité de lecture à l’échelle catalogue.

---

## 2) Structure éditoriale attendue

Chaque fiche doit suivre cet ordre de contenu (si données disponibles) :

1. **Promesse courte** (1 phrase).
2. **Description utile** (3 à 6 lignes).
3. **Bénéfices / usages** (liste courte).
4. **Informations pratiques** (ingrédients, conservation, conseils).
5. **Spécifications** (données factuelles).

Règle transversale :

- ne pas afficher de section vide ;
- ne pas inventer de contenu pour combler un manque.

---

## 3) Règles par bloc

## 3.1 Promesse courte

Attendu :

- 1 phrase claire (max 140 caractères recommandés) ;
- ancrée dans le produit réel (goût, usage, origine, texture) ;
- compréhensible immédiatement.

À éviter :

- slogans génériques ;
- superlatifs non prouvables ;
- promesses santé/réglementaires non maîtrisées.

Exemple OK :

- `Galettes de manioc croustillantes, au goût authentique des Antilles.`

Exemple KO :

- `Le meilleur produit du marché, incomparable et révolutionnaire.`

## 3.2 Description utile

Attendu :

- texte concret, orienté décision d’achat ;
- informations actionnables (saveur, texture, moment de consommation, format) ;
- paragraphe lisible (phrases courtes).

À éviter :

- récit trop abstrait ;
- duplication mot pour mot de la promesse ;
- jargon marketing.

## 3.3 Bénéfices / usages

Attendu :

- 2 à 4 points maximum ;
- bénéfices réalistes, centrés usage client ;
- formulations simples (verbe + bénéfice).

Exemple :

- `À déguster en collation ou au petit-déjeuner.`
- `Se marie bien avec confitures et boissons chaudes.`

## 3.4 Ton C-Kreyol

Principes :

- chaleureux, sincère, accessible ;
- valorise l’authenticité sans folklore artificiel ;
- proche du client, jamais agressif.

Style recommandé :

- phrases courtes ;
- vocabulaire concret ;
- rythme sobre et lisible.

## 3.5 Sincérité de l’information

Obligations :

- ne publier que des informations vérifiables ;
- éviter toute allégation non documentée ;
- préférer le factuel au promotionnel.

Interdit :

- promesse logistique non tenue ;
- bénéfices santé non validés ;
- origine affichée si non renseignée de façon fiable.

---

## 4) Checklist éditoriale rapide (avant publication)

- [ ] Promesse courte présente et crédible.
- [ ] Description utile rédigée, sans duplication.
- [ ] Bénéfices/usages concrets et réalistes.
- [ ] Ton cohérent C-Kreyol (chaleureux, clair, sincère).
- [ ] Aucune section vide rendue.
- [ ] Aucune allégation non vérifiable.

---

## 5) Gouvernance éditoriale minimale

- **Responsable contenu** : rédige et met à jour les fiches.
- **Référent MOA** : valide le ton, la sincérité, la cohérence marque.
- **Rythme recommandé** : revue hebdomadaire des fiches enrichies.

Priorité de traitement :

1. fiches pauvres ;
2. fiches moyennes ;
3. optimisation des fiches riches.
